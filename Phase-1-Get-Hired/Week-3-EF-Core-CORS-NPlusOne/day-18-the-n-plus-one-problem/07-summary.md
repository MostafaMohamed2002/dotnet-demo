# Summary — Day 18: The N+1 Problem

## What You Learned

- **SQL Observability**: How to use `appsettings.json` to expose the SQL generated by EF Core.
- **The N+1 Pattern**: Recognizing the "1 query for the root, N queries for the children" disaster.
- **Eager Loading**: Using `.Include()` and `.ThenInclude()` to flatten the data retrieval into a single JOIN-based query.
- **Projections**: Using `.Select()` to fetch only the necessary columns and aggregate data (like `Count()`) on the server side.
- **IQueryable vs IEnumerable**: The "Performance Cliff"—knowing that `.ToList()` terminates the SQL generation and moves the execution to memory.

## What This Unlocks

You now possess the primary tool for optimizing EF Core applications. You can identify performance bottlenecks by looking at logs and fix them by shifting logic from C# memory to SQL Server.

## Revisit Before Next Session

- Ensure you can explain exactly why `ToList().Where()` is slower than `Where().ToList()`.
- Practice using `.Select()` to create DTOs directly from the database.
